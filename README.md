# Lokesh Andhavarapu — Developer Portfolio

A personal portfolio website showcasing my background, technical skills, internship experience, projects, education, certifications, workshops, and contact information.

🌐 **Live website:** https://lokesh-portfolio-coral.vercel.app  
💻 **GitHub repository:** https://github.com/LuckyLoki1432/lokesh-portfolio

## About the project

This portfolio is built as a lightweight static website using HTML, CSS, and JavaScript. It provides a central place to learn about my work, explore selected projects, view certificates, and contact me.

## Features

- Introduction and professional profile
- Technical and professional skills
- Internship experience
- Featured project summaries
- Education history
- Certificate previews and category filters
- Workshops, training, and hackathon activities
- Contact details and a message form
- Mobile navigation

## Technologies used

| Technology | Purpose |
| --- | --- |
| HTML5 | Page structure and content |
| CSS3 | Styling and responsive layout |
| JavaScript | Interactive sections and dynamic content |
| Google Apps Script | Contact-form request handling |
| Google Sheets | Contact-message storage (when the Apps Script is configured correctly) |
| Vercel | Hosting and deployment |
| Git and GitHub | Version control and source code hosting |

## Run locally

This is a static website and does not require a package installation or build step.

1. Clone the repository:

   ```bash
   git clone https://github.com/LuckyLoki1432/lokesh-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd lokesh-portfolio
   ```

3. Open `index.html` in your browser.

   You can also open the folder in Visual Studio Code and use the Live Server extension.

## Project structure

The main website files are:

- `index.html` — page content, portfolio data, and JavaScript interactions
- `style.css` — website styles and layout
- `assets/` — supporting files such as the resume and certificate documents

Keep the referenced asset paths and filenames consistent with the links in the website.

## Deployment

The project is connected to Vercel.

- **Production URL:** https://lokesh-portfolio-coral.vercel.app
- **Production branch:** `main`

Push changes to the `main` branch to trigger a new deployment through the GitHub–Vercel integration.
